# Phase 6 preregistration: recursive pass 2 on pass-1 FEATURES, scored as a TREE (written before any variant number exists)

Date: 2026-11-09. Committed before training starts. Code: `train/p6_pass2_tree.py`, `bench/p6refine/timing.py`, `bench/p6refine/run_box.sh`.

## Baseline to beat
Official `tencent/Qwen3-8B-DSpine-b16`, best-first tree N=48 nodes (incl. anchor), depth cap 31, Qwen3-8B, A100, T=0, c=1:
engine tau 11.29, 627 tok/s (6.9x AR), round time 1000 * 11.29 / 627 = 18.0 ms (docs/phase2-findings.md). Engine chain b16: tau 7.99.

## Proxy (offline, teacher-forced)
- Eval data: 256 held-out prompts (open-perfectblend, eval-decontaminated by `train/prep_prompts.py`, disjoint from training prompts),
  responses generated by Qwen3-8B itself at **T=0 (greedy)**, thinking off, max 1536 new tokens. Because the responses are the target's
  greedy continuation, walking a draft tree along the data tokens = walking it along the target greedy path.
- 128 seeded random anchors per sequence (`torch.manual_seed(1234 + first index of the micro-batch)`), identical for every model.
- Per block: top-16 candidates per position from lm_head(final hidden), DSpine transition table [31 x 16 pred x 16 cand]
  (`DSpineDraftModel.transition_scores`), and:
  - **proxy chain tau** = DSpine refined greedy chain (`select_cached`) over 15 drafts (= engine chain b16), bonus counted;
  - **proxy tree tau** = best-first tree, same rule as the engine kernel (`bench/p2tree/tree_kernels.py`: node score = joint
    softmax(table row) probability, expand top-8 children per node, N-1 pops), N=48, depth cap 31, walked along the data path, bonus counted.
  - Also logged (not used for the decision): N=16/32/64, chain over 31 drafts, backbone-argmax chains, candidate prefix coverage.
- **Proxy validation** (official weights): report proxy tree tau, proxy chain tau and their ratio vs the engine ratio 11.29 / 7.99 = 1.413.
  The proxy is accepted as a ranking tool if that ratio is within 1.413 +- 15% (1.20 .. 1.62). If it is outside, results are still
  reported, flagged as weaker evidence, and the decision rule below is unchanged.

## Variants (trained once each, no hyperparameter search; numbers reported at the final step, not best-of)
Both: on-policy w.r.t. the frozen pass 1 (official b16 weights at block 36; their inputs are pass 1's own outputs for the same
anchors), warm start built so that **step 0 reproduces pass 1 exactly** (checked: step-0 proxy taus must equal the official ones).
Training: Phase 3 data recipe (Qwen3-8B regenerated responses, T=0.7, ~10K sequences), standard SpecForge DSpine objective
(gamma 7, no correct-predecessor curriculum), 300 optimizer steps x 32 sequences x 64 anchors, cosine LR with 5% warmup,
AdamW fp32 master, clip 1.0. Evals at steps 0, 150, 300.
- **V1 (full pass 2)**: trainable copy of the official 5-layer drafter at block 32; block input at position t =
  MASK embedding + sum_{o=0..4} W_o h1[t+o] (h1 = pass-1 normed final hidden; W_o zero-init). Gives pass 2 a lookahead over
  pass 1's beliefs (pass 1 is block-causal and never sees later positions). LR 1e-4. Outputs its own candidates + table -> tree.
- **V2 (small pass 2)**: 2 new DSpine layers on pass-1's last-layer pre-injection residual + sum_{o=1..4} W_o h1[t+o]
  (layers init from official layers 3,4 with o_proj/down_proj zeroed; context projection shared with pass 1, frozen). LR 2e-4.
  Two tree builds: (a) own candidates, (b) pass-1 candidates rescored with the pass-2 table (no second lm_head).

## Cost model
`bench/p6refine/timing.py`: CUDA-graph replica of one draft round's GPU work at bs=1 (48-token block, 1024 cached context, 12 new
context rows, lm_head/top-16, transition table). Extra time of pass 2 in the engine is estimated as
dT = 3.15 ms (engine draft time at block 48-64, Phase 2) x t_bench(pass 2) / t_bench(pass 1). Pass 1's own work is not reduced (conservative).
Estimated tok/s = 627 x (proxy tree tau_variant / proxy tree tau_official) x 18.0 / (18.0 + dT).

## Decision rule (per variant/tree-build pair; there are 3 pairs: V1, V2-own, V2-p1cand)
PASS iff BOTH
1. proxy tree tau (N=48) >= 1.05 x official proxy tree tau (N=48) on the same blocks, and
2. estimated tok/s > 627.
Otherwise KILL. Only a PASS triggers engine integration (Phase 2 protocol: 5 datasets x 40 prompts, T=0, c=1, plus the teacher-forced
losslessness check). With 3 pairs and paired bootstrap 95% CIs (over sequences) reported, a pair whose point estimate passes but
whose CI lower bound is below 1.05 is reported as "marginal pass" and still goes to the engine only if budget allows.
